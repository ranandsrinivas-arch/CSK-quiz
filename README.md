# Project Documentation

This is the documentation for the CSK Quiz project. It includes information about the project setup, usage, and other relevant details.

## Installation

To install the necessary dependencies, run:

```
npm install
```

## Usage

To start the quiz application, use the following command:

```
npm start
```
